## Project Description

This is my first GitHub repository, created for my IT415 activity
"Create Your First GitHub Repository and Personal CV Page." It is a
simple, one-page personal CV website built with plain HTML and CSS,
showing my profile, education, skills, and contact information.

## Features

- Clean, responsive layout that works on desktop and mobile
- Simple header navigation linking to each section
- Profile section with a short introduction
- Education section with my school details
- Skills section listing my current skills
- Contact section with my email

## Technologies Used

- HTML5
- CSS3 (no frameworks or libraries)
